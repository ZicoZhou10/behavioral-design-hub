Quick Start

Copy and paste this into any HTML page:

<div id="bds-widget"></div>
<script src="https://behavioral-design-hub.github.io/embed/embed.js"></script>

That's it. The widget auto-renders inside the #bds-widget div.

Event API

The widget emits custom events you can listen for:

// Listen for assessment completion
document.addEventListener('bds:complete', function(e) {
  console.log('Score:', e.detail.score);          // 0-100
  console.log('Dimensions:', e.detail.dimensions); // [{name, score}, ...]
});

// Listen for individual answers
document.addEventListener('bds:answer', function(e) {
  console.log('Question', e.detail.question, '→', e.detail.value);
});

// Listen for restart
document.addEventListener('bds:restart', function(e) {
  console.log('User restarted the assessment');
});
Use cases for the event API: Show a custom CTA after completion, log scores to your own analytics, trigger a chatbot, display a comparison with industry benchmarks, or personalize your page content based on the user's weakest dimension.

Parameters Reference

Attribute Default Description
data-theme "dark" "dark" or "light"
data-ref hostname Your site name for attribution tracking
data-target "bds-widget" Container element ID
data-width "100%" Widget width (CSS value)
data-max-width "720px" Maximum width (CSS value)

Platform-Specific Guides

WordPress

Use a "Custom HTML" block and paste the two-line embed code. Works in both Classic and Gutenberg editors.

Ghost / Substack / Medium

These platforms restrict embedded scripts. Instead, link to the full assessment:
https://behavioral-design-hub.github.io/tools/behavioral-design-score/?ref=your-newsletter

Notion

Use the /embed block and paste:
https://behavioral-design-hub.github.io/embed/?theme=light&ref=notion

Dev.to / Hashnode

Use the liquid tag or embed block with the direct iframe URL above.
