Quick Start

// Fetch all products
fetch('https://zicozhou10.github.io/behavioral-design-hub/api/v1/products.json')
  .then(r => r.json())
  .then(data => console.log(data.products));

// Fetch a single product
fetch('https://zicozhou10.github.io/behavioral-design-hub/api/v1/products/figma.json')
  .then(r => r.json())
  .then(product => console.log(product.scores));

// Compare two products
fetch('https://zicozhou10.github.io/behavioral-design-hub/api/v1/compare/figma-vs-shopify.json')
  .then(r => r.json())
  .then(cmp => console.log(cmp.overall_winner));

Scoring Dimensions

Each product is scored 0–10 on five research-backed behavioral science dimensions:

{
  "choice_architecture": 9,    // How well defaults and option framing guide decisions
  "cognitive_load": 7,         // How effectively complexity is managed
  "motivation_design": 8,      // How intrinsic/extrinsic motivation is leveraged
  "trust_transparency": 7,     // How trust is built and maintained
  "ethical_alignment": 7       // How ethical the behavioral techniques are
}
// Total = sum of 5 dimensions (max 50)
// Percentage = total / 50 * 100
